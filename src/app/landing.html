Inside GoRs.

&T

Ownership and borrowing

Borrow with &T or &mut T. The main compiler checks moves and conflicting borrows before generating code.

?

Errors in the type system

Make failures explicit with Result, propagate them with ?, and handle each outcome with match.

C23

A self-hosting bootstrap

The bootstrap compiler emits C23, reproduces its own generated C, and can build and run its supported subset without Go.
