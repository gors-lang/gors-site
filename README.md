# GoRs website

The GoRs landing page, built with Angular, TypeScript, and Tailwind CSS 4.

```sh
bun install
bun run start
```

Open `http://localhost:4200`. To build the static site, run `bun run build`.
The production output goes to `dist/gors-site/browser`.

The [public site](https://gors-lang.github.io/gors-site/) is deployed to GitHub
Pages on pushes to `main`.
